# GERM 203 Vocab Review

A single-page vocabulary study app for German B1 learners. Built with vanilla HTML, CSS, and JavaScript.

## Features

**Four Study Modes:**

- **Flashcards** — Flip cards to reveal translations. Supports shuffle, direction toggle (DE→EN / EN→DE), and keyboard navigation.
- **Match** — Timed pair-matching game. Connect German words to English translations. Configurable pair counts (4/6/8/10).
- **Quiz** — Multiple choice questions with configurable count (10/20/all) and direction options.
- **Typing** — Type translations from memory. Includes umlaut buttons (ä, ö, ü, ß) for English keyboards. Accepts alternate spellings (e.g., "ae" for "ä").

**Additional Features:**

- Lesson selector with 18 lessons (448 words total)
- Progress tracking within each mode
- Results summary with missed words review
- Responsive design for mobile and desktop
- Keyboard shortcuts (Enter to submit, arrow keys for flashcards)

## Usage

Open `wortschatz.html` in any modern browser. No server or build step required.
